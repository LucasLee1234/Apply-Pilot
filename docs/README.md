# Apply Pilot Documentation

This directory contains all project documentation and written work outside application code. All documents are written in English.

Documentation may include:

- Requirements analysis and product scope.
- User scenarios, workflows, and acceptance criteria.
- System architecture and technical design.
- API and data model specifications.
- Development plans and decision records.
- Testing plans, user guides, and operational instructions.

The project uses TypeScript and React for the frontend, and Python and FastAPI for the backend, with a multi-agent system to support job applications on company career websites.

Detailed requirements will be documented as they are discussed and confirmed.
